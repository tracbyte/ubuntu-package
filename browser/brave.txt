install:
========
1. Update the package list and install prerequisites
sudo apt update && sudo apt install curl -y && \

2. Add the official Brave signing key
curl -fSsL https://brave-browser-apt-release.s3.brave.com/brave-browser-archive-keyring.gpg | sudo gpg --dearmor | sudo tee /usr/share/keyrings/brave-browser-archive-keyring.gpg > /dev/null && \

3. Add the official Brave Browser repository
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/brave-browser-archive-keyring.gpg] https://brave-browser-apt-release.s3.brave.com/ stable main" | sudo tee /etc/apt/sources.list.d/brave-browser-release.list && \

4. Update package lists again and install Brave
sudo apt update && sudo apt install brave-browser -y

update:
=======
1. Refresh system repository listings and upgrade Brave Browser to the latest stable release
sudo apt update && sudo apt install --only-upgrade brave-browser -y

remove completely:
==================
1. Uninstall the Brave application and system configurations
sudo apt purge brave-browser -y && \

2. Remove the repository setup and signing keys
sudo rm -f /etc/apt/sources.list.d/brave-browser-release.list && \
sudo rm -f /usr/share/keyrings/brave-browser-archive-keyring.gpg && \

3. Clean up leftover system packages and refresh package lists
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all user profiles, history, passwords, and cache files
rm -rf ~/.config/BraveSoftware && \
rm -rf ~/.cache/BraveSoftware

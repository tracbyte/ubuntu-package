install:
========
1. Update the package list and install prerequisites
sudo apt update && sudo apt install curl -y && \

2. Add the official Google signing key
sudo curl -fSsL https://google.com | sudo gpg --dearmor | sudo tee /usr/share/keyrings/google-chrome.gpg > /dev/null && \

3. Add the official Google Chrome repository
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/google-chrome.gpg] http://google.com stable main" | sudo tee /etc/apt/sources.list.d/google-chrome.list && \

4. Update package lists again and install Chrome
sudo apt update && sudo apt install google-chrome-stable -y

update:
=======
1. Refresh system repository listings and upgrade Google Chrome to the latest stable release
sudo apt update && sudo apt install --only-upgrade google-chrome-stable -y

remove completely:
==================
1. Uninstall the Chrome application and system configurations
sudo apt purge google-chrome-stable -y && \

2. Remove the repository setup and signing keys
sudo rm -f /etc/apt/sources.list.d/google-chrome.list && \
sudo rm -f /usr/share/keyrings/google-chrome.gpg && \

3. Clean up leftover system packages and refresh package lists
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all user profiles, history, passwords, and cache files
rm -rf ~/.config/google-chrome && \
rm -rf ~/.cache/google-chrome

install:
========
1. Completely remove the slower pre-installed Snap version of Firefox
sudo snap remove --purge firefox && \

2. Create a secure folder for the repository keys
sudo install -d -m 0755 /etc/apt/keyrings && \

3. Import Mozilla’s official security signing key
curl -fsSL https://packages.mozilla.org/apt/repo-signing-key.gpg | sudo tee /etc/apt/keyrings/packages.mozilla.org.asc > /dev/null && \

4. Add Mozilla’s official repository to your system sources
echo "deb [signed-by=/etc/apt/keyrings/packages.mozilla.org.asc] https://packages.mozilla.org/apt mozilla main" | sudo tee /etc/apt/sources.list.d/mozilla.list && \

5. Tell Ubuntu to prioritize Mozilla's repository over the default Snap store
echo '
Package: *
Pin: origin packages.mozilla.org
Pin-Priority: 1000
' | sudo tee /etc/apt/preferences.d/mozilla && \

6. Refresh your system and install the high-performance Firefox application
sudo apt update && sudo apt install firefox -y

update:
=======
1. Refresh system repository listings and upgrade the native Mozilla Firefox package
sudo apt update && sudo apt install --only-upgrade firefox -y

remove completely:
==================
1. Uninstall the Firefox software and its system packages
sudo apt purge firefox -y && \

2. Delete the custom Mozilla repository lists and preference files
sudo rm -f /etc/apt/sources.list.d/mozilla.list /etc/apt/preferences.d/mozilla /etc/apt/keyrings/packages.mozilla.org.asc && \

3. Clean up leftover dependencies and update system indexes
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all user profiles, history, saved passwords, bookmarks, cache, and Snap leftovers
rm -rf ~/.mozilla && \
rm -rf ~/.cache/mozilla && \
rm -rf ~/snap/firefox

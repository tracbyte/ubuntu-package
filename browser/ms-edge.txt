install:
========
1. Update the package list and install prerequisites
sudo apt update && sudo apt install curl -y && \

2. Add the official Microsoft signing key
curl -fSsL https://packages.microsoft.com/keys/microsoft.asc | sudo gpg --dearmor | sudo tee /usr/share/keyrings/microsoft-edge.gpg > /dev/null && \

3. Add the official Microsoft Edge repository
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/microsoft-edge.gpg] https://packages.microsoft.com/repos/edge stable main" | sudo tee /etc/apt/sources.list.d/microsoft-edge.list && \

4. Update package lists again and install Microsoft Edge
sudo apt update && sudo apt install microsoft-edge-stable -y

update:
=======
1. Refresh system repository listings and upgrade Microsoft Edge to the latest stable release
sudo apt update && sudo apt install --only-upgrade microsoft-edge-stable -y

remove completely:
==================
1. Uninstall the Microsoft Edge application and system configurations
sudo apt purge microsoft-edge-stable -y && \

2. Remove the repository setup and signing keys
sudo rm -f /etc/apt/sources.list.d/microsoft-edge.list && \
sudo rm -f /usr/share/keyrings/microsoft-edge.gpg && \

3. Clean up leftover system packages and refresh package lists
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all user profiles, history, passwords, and cache files
rm -rf ~/.config/microsoft-edge && \
rm -rf ~/.cache/microsoft-edge

install:
========
1. Update the package list and install prerequisites
sudo apt update && sudo apt install curl gnupg -y && \

2. Add the official Tor Project signing key
curl -fSsL https://deb.torproject.org/torproject.org/A3C4F0F979CAA22CDBA8F512EE8CBC9E886DDD89.asc | sudo gpg --dearmor | sudo tee /usr/share/keyrings/tor-archive-keyring.gpg > /dev/null && \

3. Add the official Tor Project repository
echo "deb [signed-by=/usr/share/keyrings/tor-archive-keyring.gpg] https://deb.torproject.org/torproject.org $(lsb_release -sc) main" | sudo tee /etc/apt/sources.list.d/torproject.list && \

4. Update package lists again and install Tor Browser Launcher
sudo apt update && sudo apt install torbrowser-launcher deb.torproject.org-keyring -y

update:
=======
1. Refresh system repository listings and upgrade Tor Browser Launcher to the latest stable release
sudo apt update && sudo apt install --only-upgrade torbrowser-launcher -y

remove completely:
==================
1. Uninstall the Tor Browser Launcher package and system configurations
sudo apt purge torbrowser-launcher -y && \

2. Remove the repository setup and signing keys
sudo rm -f /etc/apt/sources.list.d/torproject.list && \
sudo rm -f /usr/share/keyrings/tor-archive-keyring.gpg && \

3. Clean up leftover system packages and refresh package lists
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all downloaded browser data, user profiles, and cache files
rm -rf ~/.local/share/torbrowser && \
rm -rf ~/.cache/torbrowser

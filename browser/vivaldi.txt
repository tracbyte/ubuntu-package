install:
========
1. Update the package list and install prerequisites
sudo apt update && sudo apt install curl -y && \

2. Add the official Vivaldi signing key
curl -fSsL https://repo.vivaldi.com/archive/linux_signing_key.pub | sudo gpg --dearmor | sudo tee /usr/share/keyrings/vivaldi-browser.gpg > /dev/null && \

3. Add the official Vivaldi repository
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/vivaldi-browser.gpg] https://repo.vivaldi.com/archive/deb/ stable main" | sudo tee /etc/apt/sources.list.d/vivaldi.list && \

4. Update package lists again and install Vivaldi
sudo apt update && sudo apt install vivaldi-stable -y

update:
=======
1. Refresh system repository listings and upgrade Vivaldi to the latest stable release
sudo apt update && sudo apt install --only-upgrade vivaldi-stable -y

remove completely:
==================
1. Uninstall the Vivaldi application and system configurations
sudo apt purge vivaldi-stable -y && \

2. Remove the repository setup and signing keys
sudo rm -f /etc/apt/sources.list.d/vivaldi.list && \
sudo rm -f /usr/share/keyrings/vivaldi-browser.gpg && \

3. Clean up leftover system packages and refresh package lists
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all user profiles, history, passwords, and cache files
rm -rf ~/.config/vivaldi && \
rm -rf ~/.cache/vivaldi

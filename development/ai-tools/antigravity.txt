install:
========
# Execute the built-in easter egg script inside Python to open the web comic
python3 -c "import antigravity"

update:
=======
# Antigravity is a static, built-in Python module easter egg and cannot be updated
echo "No updates required."

clean cache:
============
# Antigravity uses standard web browser cache; no separate module cache exists
echo "No cache files created."

remove profiles:
================
# Antigravity stores no user profile data or configurations
echo "No user profiles created."

uninstall:
==========
# Close the web browser tab that automatically opened when you imported the module
echo "No files were installed. Antigravity is a built-in Python easter egg module!"

install:
========
1. Update package files, install python pipelines, and deploy Shell GPT via pip
sudo apt update && sudo apt install python3-pip -y && pip3 install sgpt --break-system-packages

update:
=======
1. Pull the latest release of the Shell GPT command-line tool via the pip pipeline
pip3 install --upgrade sgpt --break-system-packages

remove completely:
==================
1. Uninstall the Shell GPT core package from the global pip container
pip3 uninstall sgpt shell-gpt -y --break-system-packages && \

2. Wipe out your custom OpenAI API keys, local prompt histories, and cache settings
rm -rf ~/.config/shell-gpt && \
rm -rf ~/.cache/shell-gpt

install:
========
1. Update packages, install Python environments, and install both Jupyter Notebook and JupyterLab together
sudo apt update && sudo apt install python3-pip python3-venv -y && pip3 install jupyter jupyterlab --break-system-packages

update:
=======
1. Call Python's pip manager to check and upgrade JupyterLab
pip3 install --upgrade jupyterlab --break-system-packages

remove completely:
==================
1. Uninstall all Jupyter Notebook and JupyterLab packages from your system
pip3 uninstall jupyter jupyter-core jupyter-client jupyterlab notebook -y --break-system-packages && \

2. Wipe out all configurations, extensions, layout states, and cache directories
rm -rf ~/.jupyter && \
rm -rf ~/.local/share/jupyter

install:
========
1. Update packages, install Python 3 environment dependencies, and install Jupyter via pip
sudo apt update && sudo apt install python3-pip python3-venv -y && pip3 install jupyter --break-system-packages

update:
=======
1. Call Python's pip manager to check and upgrade Jupyter Notebook
pip3 install --upgrade jupyter --break-system-packages

remove completely:
==================
1. Uninstall the Jupyter package and its configuration engines via pip
pip3 uninstall jupyter jupyter-core jupyter-client jupyterlab notebook -y --break-system-packages && \

2. Wipe out all notebook configuration layouts, runtime environments, and cache data
rm -rf ~/.jupyter && \
rm -rf ~/.local/share/jupyter

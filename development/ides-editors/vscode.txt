install:
========
1. Update system tools and import the official Microsoft security signing key
sudo apt update && sudo apt install curl -y && curl -fSsL https://microsoft.com | gpg --dearmor | sudo tee /usr/share/keyrings/packages.microsoft.gpg > /dev/null && \

2. Add the official Microsoft Visual Studio Code repository to your system sources
echo "deb [arch=amd64 signed-by=/usr/share/keyrings/packages.microsoft.gpg] https://microsoft.com stable main" | sudo tee /etc/apt/sources.list.d/vscode.list && \

3. Refresh package lists and install Visual Studio Code
sudo apt update && sudo apt install code -y

update:
=======
1. Refresh system repository listings and upgrade Visual Studio Code
sudo apt update && sudo apt install --only-upgrade code -y

remove completely:
==================
1. Uninstall the VS Code application software and system components
sudo apt purge code -y && \

2. Remove the repository setup and security signing keys from the system
sudo rm -f /etc/apt/sources.list.d/vscode.list && \
sudo rm -f /usr/share/keyrings/packages.microsoft.gpg && \

3. Clean up leftover packages and refresh the system indexes
sudo apt update && sudo apt autoremove -y && \

4. Wipe out all user extensions, settings, customizations, cache, and workspace states
rm -rf ~/.config/Code && \
rm -rf ~/.vscode

install:
========
1. Update package lists and install Node.js along with the npm package manager
sudo apt update && sudo apt install nodejs npm -y

update:
=======
1. Refresh system repository listings and upgrade Node.js and npm
sudo apt update && sudo apt install --only-upgrade nodejs npm -y

remove completely:
==================
1. Uninstall Node.js, npm, and system package bindings
sudo apt purge nodejs npm -y && \

2. Clean up leftover system package dependencies
sudo apt autoremove -y && \

3. Wipe out globally installed npm packages, local caches, and Node command history
rm -rf ~/.npm && \
rm -rf ~/.node_repl_history && \
rm -rf ~/.config/configstore

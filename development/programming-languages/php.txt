install:
========
1. Update package lists and install the PHP interpreter, common CLI extensions, and package manager
sudo apt update && sudo apt install php php-cli php-common php-mbstring php-xml php-zip php-curl curl -y

update:
=======
1. Refresh system repository listings and upgrade PHP along with its core extensions
sudo apt update && sudo apt install --only-upgrade php php-cli php-common -y

remove completely:
==================
1. Uninstall PHP packages, module configurations, and CLI dependencies
sudo apt purge php* -y && \

2. Clean up leftover system package dependencies
sudo apt autoremove -y && \

3. Wipe out local Composer caches, system settings, and command history
rm -rf ~/.composer && \
rm -rf ~/.config/php

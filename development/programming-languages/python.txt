install:
========
1. Update package lists and install the full Python 3 development environment, compiler tools, and pip manager
sudo apt update && sudo apt install python3 python3-pip python3-dev python3-venv build-essential -y

update:
=======
1. Refresh system repository listings and upgrade Python 3 development tools and libraries
sudo apt update && sudo apt install --only-upgrade python3 python3-pip python3-dev python3-venv -y

remove completely:
==================
1. Uninstall pip, virtual environment packages, and development configurations
sudo apt purge python3-pip python3-dev python3-venv build-essential -y && \

2. Clean up leftover system package dependencies
sudo apt autoremove -y && \

3. Wipe out user-wide pip packages, local caches, and Python configuration profiles
rm -rf ~/.local/lib/python* && \
rm -rf ~/.cache/pip && \
rm -rf ~/.python_history

install:
========
1. Update package lists and install the Ruby interpreter, core development headers, and build tools
sudo apt update && sudo apt install ruby-full build-essential -y

update:
=======
1. Refresh system repository listings and upgrade the Ruby core environment
sudo apt update && sudo apt install --only-upgrade ruby-full -y

remove completely:
==================
1. Uninstall Ruby runtime, header files, and build environment dependencies
sudo apt purge ruby-full ruby -y && \

2. Clean up leftover system package dependencies
sudo apt autoremove -y && \

3. Wipe out installed user gems, bundle caches, and Ruby configuration files
rm -rf ~/.gem && \
rm -rf ~/.bundle && \
rm -rf ~/.irb_history

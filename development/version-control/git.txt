install:
========
1. Update your system package index and install Git with its core configuration tools
sudo apt update && sudo apt install git build-essential -y

update:
=======
1. Refresh system repository listings and upgrade Git to the latest stable system release
sudo apt update && sudo apt install --only-upgrade git -y

remove completely:
==================
1. Uninstall the Git application software and its global system package configurations
sudo apt purge git -y && \

2. Clean up leftover system package dependencies and libraries
sudo apt autoremove -y && \

3. Wipe out your global git configurations, user identity settings, cache, and credential storage keys
rm -f ~/.gitconfig && \
rm -rf ~/.config/git
